# ATM System Project

This is a comprehensive ATM System project developed during the **Programming Advices** training. It demonstrates practical application of C++ concepts such as class design, file handling, and terminal-based UI interactions.

## 🚀 Features
- **Client Management:** Manage personal information (account number, PIN, balance).
- **Authentication:** Secure login mechanism.
- **Transactions:** 
    - Quick Withdraw
    - Normal Withdraw
    - Deposit
    - Check Balance

## 🛠 Tech Stack
- **Language:** C++
- **Architecture:** Procedural/OOP hybrid
- **Storage:** Flat-file system for data persistence.
