# Make Your Pizza

A Windows Forms desktop application for customizing and ordering a pizza.

## Overview

The application lets the user build a pizza by selecting its size, crust type, toppings, and dining option. The order summary and total price are updated as selections change.

## Features

- Choose a small, medium, or large pizza
- Select thin or thick crust
- Add optional toppings:
  - Extra cheese
  - Onion
  - Mushrooms
  - Olives
  - Tomatoes
  - Green peppers
- Choose eat-in or take-out
- View the selected order details
- Calculate the total price dynamically
- Confirm the order with a success message
- Reset the form for a new order

## Technologies

- C#
- Windows Forms
- .NET Framework 4.8
- Visual Studio

## Project Structure

- `Make_Your_Pizza.sln` - Visual Studio solution file
- `Make_Your_Pizza/` - Application source code and resources
- `Form1.cs` - Main form logic
- `Form1.Designer.cs` - Windows Forms designer-generated layout
- `Resources/Pizza.jpg` - Pizza image used by the application

## How to Run

1. Open `Make_Your_Pizza.sln` in Visual Studio.
2. Restore or install the required .NET Framework 4.8 developer tools if needed.
3. Build the solution.
4. Run the application.
