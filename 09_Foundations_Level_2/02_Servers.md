# الفصل الثاني: السيرفرات والخوادم

## 📝 الدرس الأول: ما هو السيرفر (Server)؟

السلام عليكم ورحمة الله وبركاته 🙏

اليوم ننتقل إلى مفهوم جديد ومهم جداً: **السيرفر (الخادم)**. سنتعرف على ماهيته، الفرق بينه وبين الـ PC العادي، وأين يُستخدم.

---

### 🔑 التعريف الأساسي

**السيرفر = كمبيوتر متخصص يقدم خدمات للآخرين**

```
السيرفر = Serve (يخدم) + Server (خادم)
```

وظيفته الرئيسية:

- 🔹 **استقبال الطلبات** من الأجهزة الأخرى (Clients)
- 🔹 **تخزين البيانات** بشكل آمن ومنظم
- 🔹 **معالجة المعلومات** وإجراء العمليات
- 🔹 **مشاركة الموارد** والخدمات

---

### 💭 مثال عملي بسيط

تخيل مطعماً:

```
- الزبون = Client (يطلب الخدمة)
- الويتر/الموظف = Server (يقدم الخدمة)
- الطعام والشراب = البيانات والموارد

العلاقة:
الزبون → يطلب → الويتر → يجلب → الطعام
```

**نفس المبدأ في الشبكات:**

```
جهازك (Client) → يطلب ملف → السيرفر → يرسل ← الملف
```

---

## 🖥️ الفرق بين السيرفر والـ PC العادي

|      الخاصية      |    PC العادي    |       السيرفر       |
| :---------------: | :-------------: | :-----------------: |
|     **الهدف**     | 👤 لمستخدم واحد |  👥 لعدة مستخدمين   |
|    **الأداء**     |     ⚡ عادي     |  ⚡⚡⚡ عالي جداً   |
|   **الموثوقية**   |    ⚠️ متوسطة    |  ✅✅✅ عالية جداً  |
|   **الاستقرار**   |    ⏱️ ساعات     | 📅 سنوات بدون توقف  |
| **الذاكرة (RAM)** |     8-16 GB     |      64-256 GB      |
|    **المعالج**    |   معالج عادي    | معالجات متعددة قوية |
|    **التكلفة**    |     💰 رخيص     |  💰💰💰 غالي جداً   |
|    **التطبيق**    |  العمل الشخصي   |  الشركات والمؤسسات  |

---

### 💡 ملاحظة مهمة:

> **أي كمبيوتر يمكن أن يصبح سيرفر!**

إذا ركبت برنامج سيرفر (مثل Apache أو IIS) على لاب توبك، فقد حولته إلى **ويب سيرفر** (Web Server). الفرق ليس في الجهاز بل في **البرنامج والغرض**!

---

## 📊 أنواع السيرفرات (حسب الوظيفة)

### 🌐 1. Web Server (ويب سيرفر)

**الوظيفة:** استضافة وتقديم مواقع الويب

```
الزائر → يفتح الموقع → Web Server → يرسل الصفحة ← المتصفح
```

**أمثلة:** Apache, Nginx, IIS

---

### 📧 2. Mail Server (ميل سيرفر)

**الوظيفة:** استقبال وإرسال رسائل البريد الإلكتروني

```
بريدك الشخصي ← يتلقى من ← Mail Server ← يتلقى من ← صديقك
```

---

### 💾 3. Database Server (ديتابيز سيرفر)

**الوظيفة:** تخزين وإدارة قواعد البيانات

```
تطبيقك ← يطلب بيانات ← Database Server ← يعالج الاستعلام ← البيانات
```

**أمثلة:** MySQL, PostgreSQL, SQL Server

---

### 📁 4. File Server (فايل سيرفر)

**الوظيفة:** تخزين ومشاركة الملفات

```
جهازك ← يطلب ملف ← File Server ← يرسل ← الملف
```

---

### ⚙️ 5. Application Server (أبليكيشن سيرفر)

**الوظيفة:** تشغيل التطبيقات وخدمتها للمستخدمين

```
تطبيق الويب ← يطلب عملية ← App Server ← ينفذ ← النتيجة
```

---

### 🎮 6. Game Server (جيم سيرفر)

**الوظيفة:** تشغيل الألعاب متعددة اللاعبين

```
جهازك ← بيانات اللعبة ← Game Server ← تنسيق اللاعبين ← جهاز صديقك
```

---

### 🔊 7. صور أخرى متخصصة

- **DNS Server** - ترجمة أسماء المواقع
- **Print Server** - إدارة الطباعة
- **FTP Server** - نقل الملفات
- **VoIP Server** - المكالمات الصوتية عبر الإنترنت

---

## 🏗️ أشكال السيرفرات الفيزيائية

### 1️⃣ Tower Server (تاور سيرفر)

- ✅ شكل عادي مثل الـ PC
- ✅ يمكن وضعه على المكتب
- ❌ يأخذ حيزاً أكبر

---

### 2️⃣ Rack Server (راك سيرفر)

- ✅ رفيع جداً (شكل كتاب سميك)
- ✅ يُركب في خزانات خاصة (Rack)
- ✅ توفير مساحة في الـ Data Center
- 📸 **الاستخدام:** الشركات الكبرى

---

### 3️⃣ Blade Server (بليد سيرفر)

- ✅ صغير جداً وخفيف الوزن
- ✅ يُركب بكثافة عالية
- ✅ كفاءة الطاقة عالية
- 📸 **الاستخدام:** مراكز البيانات الضخمة

---

## 🏢 Data Centers (مراكز البيانات)

### ماذا هو Data Center؟

مبنى متخصص يحتوي على:

- 🖥️ مئات أو آلاف السيرفرات
- ❄️ أنظمة تكييف متقدمة (H24)
- 🔒 أمان عالي جداً
- 🔋 أنظمة كهربائية احتياطية
- 🌐 اتصالات إنترنت فائقة السرعة

### ❓ لماذا التكييف مهم؟

السيرفرات تُطلق حرارة كبيرة جداً! بدون تبريد:

```
السيرفر الساخن → الأعطال → البيانات المفقودة → الكارثة!
```

---

### 💰 التكاليف المرتبطة

- **التكييف:** 50% من التكاليف التشغيلية
- **الكهرباء:** مستمرة 24/7
- **الأمان:** حراس وأنظمة مراقبة
- **الصيانة:** فنيون متخصصون

**لهذا:** مثلاً Facebook تضع مراكز بيانات في الأماكن الباردة (القطب الشمالي) لتوفير التكييف! ❄️

---

## 📝 ملخص النقاط المهمة

✔️ **السيرفر** = كمبيوتر يقدم خدمات للآخرين  
✔️ **الفرق الرئيسي:** الأداء، الموثوقية، والاستقرار  
✔️ **أي جهاز يمكن أن يصبح سيرفر** إذا ركبت البرامج المناسبة  
✔️ **أنواع متعددة** حسب الوظيفة (ويب، بريد، قواعد بيانات، إلخ)  
✔️ **مراكز البيانات** توفر بيئة آمنة واستقرار عالي
